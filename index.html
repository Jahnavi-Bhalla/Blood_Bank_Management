BloodBankJDBC.java (Source)
Java 17 / JDBC 4.2 
import java.sql.*;
import java.util.Scanner;

// Relational Database: Blood Bank Management System JDBC
public class BloodBankJDBC {
    private static final String DB_URL = "jdbc:oracle:thin:@localhost:1521:XE";
    private static final String DB_USER = "system";
    private static final String DB_PASS = "password";

    public static void main(String[] args) {
        // 1. Load Oracle JDBC Driver
        Class.forName("oracle.jdbc.OracleDriver");

        // 2. Establish Connection
        try (Connection con = DriverManager.getConnection(DB_URL, DB_USER, DB_PASS)) {
            System.out.println("Connected to Oracle Database!");

            // 3. Parameterized INSERT using PreparedStatement
            String sqlInsert = "INSERT INTO DONOR VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)";
            PreparedStatement pstmt = con.prepareStatement(sqlInsert);
            pstmt.setString(1, "D109");
            pstmt.setString(2, "Vikramaditya");
            pstmt.setString(3, "O+");
            pstmt.setInt(4, 29);
            pstmt.setString(5, "Male");
            pstmt.setString(6, "+91 98401 99999");
            pstmt.setString(7, "Chennai");
            pstmt.setDouble(8, 14.6);
            pstmt.setString(9, "Eligible");
            int rows = pstmt.executeUpdate();
            System.out.println(rows + " row(s) inserted.");

            // 4. Transaction Management (COMMIT / ROLLBACK)
            con.setAutoCommit(false);
            // Deduct stock & fulfill emergency request...
            con.commit();
        }
    }
}
schema.sql (Oracle SQL*Plus Script)
SQL*Plus DDL 
-- Oracle SQL*Plus DDL Script
CREATE TABLE DONOR (
    DONOR_ID VARCHAR2(10) PRIMARY KEY,
    NAME VARCHAR2(100) NOT NULL,
    BLOOD_GROUP VARCHAR2(5) NOT NULL,
    AGE NUMBER(3) CHECK (AGE BETWEEN 18 AND 65),
    GENDER VARCHAR2(10),
    PHONE VARCHAR2(20) NOT NULL,
    CITY VARCHAR2(50) NOT NULL,
    HEMOGLOBIN NUMBER(4,1),
    STATUS VARCHAR2(15) DEFAULT 'Eligible'
);

CREATE TABLE BLOOD_STOCK (
    BLOOD_GROUP VARCHAR2(5) PRIMARY KEY,
    UNITS_AVAILABLE NUMBER(5) DEFAULT 0,
    MAX_CAPACITY NUMBER(5) DEFAULT 50,
    MIN_SAFE_LEVEL NUMBER(5) DEFAULT 12,
    STATUS VARCHAR2(20) DEFAULT 'ADEQUATE'
);

CREATE TABLE HOSPITAL_REQUESTS (
    REQUEST_ID VARCHAR2(15) PRIMARY KEY,
    HOSPITAL_NAME VARCHAR2(100) NOT NULL,
    PATIENT_NAME VARCHAR2(100) NOT NULL,
    BLOOD_GROUP VARCHAR2(5) NOT NULL,
    UNITS_REQUESTED NUMBER(3),
    URGENCY VARCHAR2(25),
    STATUS VARCHAR2(15) DEFAULT 'Pending'
);

COMMIT;

System Setup, Installation & Execution Guide

System Instructions: Step-by-step installation commands, database connectivity driver configuration (Java JDBC, ODBC DSN, SQL*Plus), and frontend execution instructions.

1 Web Application & REST Server Execution (Node.js)

Runs the client dashboard, interactive SQL engine, and eligibility processor on port 3000.

# Open PowerShell or Command Prompt in project folder
cd c:\Users\jahna\bloodBank

# Start the web & REST API server
node server.js

Open browser at http://localhost:3000 or open login.html for the dedicated staff login page.

2 Java JDBC Driver Installation & Program Compilation

Fulfills Java JDBC requirement using Type-4 Oracle JDBC Driver (ojdbc8.jar / ojdbc11.jar) or PostgreSQL/H2 driver.

# 1. Download Oracle JDBC Driver (if not already downloaded)
curl -O https://repo1.maven.org/maven2/com/oracle/database/jdbc/ojdbc8/19.8.0.0/ojdbc8-19.8.0.0.jar
ren ojdbc8-19.8.0.0.jar ojdbc8.jar

# 2. Compile Java JDBC Application
javac -cp ".;ojdbc8.jar" BloodBankJDBC.java

# 3. Run Java JDBC Application
java -cp ".;ojdbc8.jar" BloodBankJDBC

Includes full parameter binding via PreparedStatement, result iteration with ResultSet, and transactional dispatch with commit() & rollback().

3 Oracle Database Relational Schema Initialization (SQL*Plus)

Loads normalized relational tables, primary keys, foreign keys, and constraints into Oracle Express Edition (XE).

# Connect to Oracle Database via SQL*Plus
sqlplus system/password@localhost:1521/XE

# Execute the schema DDL script
@schema.sql

# Verify created relational tables
SELECT table_name FROM user_tables;

4 ODBC Data Source Name (DSN) Configuration (Windows)

Fulfills Lab Exercise 11 ODBC front-end interface configuration.

  1. Press Win + R, type odbcad32.exe, and press Enter to open ODBC Data Source Administrator (64-bit).
  2. Select the System DSN tab and click Add....
  3. Select Oracle in OraClient11g_home1 (or Oracle in XE) and click Finish.
  4. Fill in the parameters:
    • Data Source Name (DSN): BloodBankDSN
    • Description: Blood Bank Management System ODBC
    • TNS Service Name: XE
    • User ID: system
  5. Click Test Connection, enter password password, and verify "Connection successful".
  6. Click OK to save the System DSN.
